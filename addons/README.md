# Bedrock add-ons

Behavior and resource packs for Minecraft Bedrock. Unlike the plugins in the other folders, these
don't need a particular server - they work in single-player worlds, Realms, and on Bedrock
Dedicated Server with or without Endstone.

| Add-on | What it does |
|---|---|
| [simple-auction-house](simple-auction-house/) | Player-to-player auction house with a chest menu (`/ah`, `/ahsell`, `/ahmenu`) |
